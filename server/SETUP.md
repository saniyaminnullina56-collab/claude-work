# Пошаговый запуск «Выручай-комнаты» (для тех, кто не программист)

Что получится: бот в Telegram с кнопкой «Клуб», приложение с каталогом и конспектами, конспекты сами подтягиваются из вашего Notion.
Понадобится около часа и аккаунты: Telegram, Notion, GitHub (репозиторий у вас уже есть) и хостинг.

> **Главное правило про секреты.** Токены — это пароли. Их вставляют только в настройки хостинга (раздел *Variables*).
> Не отправляйте их в чат, не вставляйте в код и не сохраняйте в репозитории GitHub.

---

## Шаг 1. Бот в Telegram (≈5 минут)
1. В Telegram найдите **@BotFather** → отправьте `/newbot`.
2. Придумайте название (например, «Выручай-комната») и имя бота на латинице, оканчивающееся на `bot`.
3. BotFather пришлёт **токен** — длинная строка вида `123456789:AAH…`. Это ваш `BOT_TOKEN`. Сохраните его в заметках.
4. Узнайте **свой Telegram ID**: напишите боту **@userinfobot** — он ответит числом (`Id: 123456789`). Это ваш `ADMIN_IDS`. Только этот ID будет организатором.

## Шаг 2. Токен Notion (≈10 минут)
Зачем: сервер работает сам, без меня и без вашего компьютера, поэтому ему нужен собственный «пропуск» в Notion.
Пропуск читает **только те страницы, которые вы ему откроете**, и только читает — ничего не изменяет.

1. Откройте в браузере **notion.so/profile/integrations** (или notion.so/my-integrations).
2. Нажмите **«Новая интеграция» / New integration**.
3. Название — любое («Выручай-комната»). Рабочее пространство — то, где лежит «Читальня». Тип — **Internal (внутренняя)**. Сохраните.
4. Откроется страница интеграции. Найдите **«Internal Integration Secret» / «Секрет интеграции»** → **Show / Показать → Copy / Копировать**.
   Строка начинается с `ntn_` или `secret_`. Это ваш `NOTION_TOKEN`.
5. На вкладке **Capabilities / Возможности** оставьте галочку только на **«Read content» / «Чтение содержимого»**.
6. **Откройте интеграции доступ к конспектам** (без этого шага будет ошибка «страница не найдена»):
   в Notion откройте страницу **«Читальня»** → меню **«⋯»** в правом верхнем углу → **«Подключения» / Connections** → найдите вашу интеграцию → подтвердите.
   Доступ автоматически распространится на вложенные страницы «Конспекты по прочитанным книгам 2024, 2025, 2026».
7. **ID страницы «Читальня»**: откройте её, скопируйте ссылку из адресной строки. В конце ссылки 32 символа — это ID.
   Для вашей страницы: `ca66f65aed68432fabb911951b8e2f62`. Это `NOTION_ROOT_PAGE_ID`.

## Шаг 3. Хостинг (≈20 минут)
Приложению нужен сервер, который работает постоянно, и **постоянный диск** для базы (при перезапуске данные не должны пропадать).
Вариант, где всё делается мышкой, — **Railway** (railway.com; платный, порядка 5 долларов в месяц, актуальные условия смотрите на сайте).
Другие подходящие варианты: Render, Fly.io или обычный VPS.

1. Зарегистрируйтесь на railway.com через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий `claude-work`, ветку `claude/book-club-mini-app-oluz9l` (или main, когда изменения будут влиты).
3. В настройках сервиса (**Settings**): **Root Directory** = `server`. Railway сам найдёт Dockerfile.
4. **Volumes → Add Volume**, путь монтирования (*Mount path*): `/data`.
5. **Settings → Networking → Generate Domain**. Получится адрес вида `https://что-то.up.railway.app`. Это ваш `PUBLIC_URL`.
6. Раздел **Variables → New Variable**. Добавьте по одной:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен из шага 1 |
| `ADMIN_IDS` | ваш Telegram ID из шага 1 |
| `PUBLIC_URL` | адрес из пункта 5, без `/` в конце |
| `WEBHOOK_SECRET` | любая случайная строка из 20+ латинских букв и цифр (придумайте сами) |
| `NOTION_TOKEN` | токен из шага 2 |
| `NOTION_ROOT_PAGE_ID` | `ca66f65aed68432fabb911951b8e2f62` |
| `DB_FILE` | `/data/bookclub.sqlite` |
| `NODE_ENV` | `production` |

7. Сервис перезапустится. Откройте `ВАШ_АДРЕС/healthz` — должно появиться `{"ok":true}`.

Бот настраивается **сам при запуске** (webhook, кнопка «Клуб», команды): ничего вводить в терминале не нужно.

## Шаг 4. Первый запуск
1. В Telegram откройте своего бота → `/start` → нажмите **«Открыть клуб»** (или кнопку «Клуб» внизу).
2. Вы увидите приветствие: выберите аватар, имя, цель на год. Вы — организатор, потому что ваш ID указан в `ADMIN_IDS`.
3. **Профиль → «Конспекты из Notion» → «Синхронизировать сейчас».** Первый раз займёт несколько минут (около 30 конспектов).
4. Результат на той же карточке:
   - «Привязано: N» — конспекты нашли свои книги;
   - «Конспекты без книги» — этих книг нет в каталоге или название не сопоставилось. Привяжите вручную или нажмите **«Создать новую книгу»**.
   - красная строка с ошибкой — она подскажет, что исправить (неверный токен, не открыт доступ к «Читальне»).
5. **Профиль → «Ссылка на канал»**: уже подставлена ссылка https://t.me/numerical_reflections_msi (меняется там же).
6. **Профиль → «Настройки доступа»**: общий код и коды по книгам для платных конспектов.

## Если что-то не работает
| Симптом | Причина и решение |
|---|---|
| Приложение пишет «Откройте из Telegram» | Открыли ссылку в браузере. Открывайте через бота |
| `/start` не отвечает | Проверьте `BOT_TOKEN`, `PUBLIC_URL` (https, без `/`), `WEBHOOK_SECRET`. Логи сервиса покажут «Не удалось настроить бота» |
| «Notion не принял токен» | Скопируйте секрет заново, без пробелов, в `NOTION_TOKEN` |
| «Notion не нашёл страницу» | Шаг 2.6: «Читальня» → «⋯» → «Подключения» → ваша интеграция; проверьте `NOTION_ROOT_PAGE_ID` |
| Данные пропали после перезапуска | Не создан диск (шаг 3.4) или `DB_FILE` не `/data/…` |
| Я не вижу кнопок организатора | Ваш Telegram ID не указан в `ADMIN_IDS` |

## Резервные копии
Вся база — один файл `/data/bookclub.sqlite`. Периодически скачивайте его с хостинга (на Railway — через Volumes или CLI).
