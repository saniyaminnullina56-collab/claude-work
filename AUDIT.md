# Аудит «Выручай-комнаты»

## Исправлено
- `const DEFAULT_PRO_CODE` объявлена дважды в двух `<script>` (SyntaxError) — весь основной скрипт не выполнялся, приложение было пустым. Оставлено одно объявление со значением `""`.

## Критично (не исправлено)
1. `ADMIN_PASS = "777"` в клиентском коде; `D.profile.isAdmin` — флаг в localStorage. Любой становится админом через DevTools.
2. Коды доступа (`config/proCode`, `bookPayInfo[*].code`) читаются из Firebase каждым клиентом; `vrk-pro` в localStorage ставится вручную.
3. `notes.json` (~2 МБ платных конспектов) публично лежит на хостинге.
4. Firebase в «test mode»: правила БД, судя по коду, открыты на чтение и запись всем.
5. Идентичность участниц — имя из профиля, без аккаунта.

## План для Telegram Mini App
Авторизация через `initData` (проверка подписи на сервере), роли и доступ к конспектам проверяются на сервере, конспекты отдаются по API только после проверки, оплата цифрового контента — Telegram Stars.

## Статус (после переработки)
Пункты 1–5 закрыты серверной частью (`server/`, см. `server/README.md`). Дополнительно найдено и исправлено:
- комментарии/цитаты/вопросы добавлялись через `push` (объект в Firebase), а код ожидал массив — после перезагрузки `D.comments[bid].push` падал;
- конспекты в `notes.json` были экранированы дважды (`\\n`, `\\"`) и содержали теги Notion — очищаются при импорте;
- первый запуск организатора не записывал стартовые книги на сервер.
